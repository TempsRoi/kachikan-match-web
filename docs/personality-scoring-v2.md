# フタリシル 性格軸・関係スタイル判定仕様 v2

最終更新: 2026-08-22  
実装識別子: `scoringVersion: "v2"`

## 1. 目的

24問の回答から、ユーザーの日常的な関わり方を4つの連続軸で表現し、その組み合わせをキャッチーな「関係スタイル」として提示する。

- 既存の世界観名だけでは伝わりにくかった性格傾向を、生活に近い言葉で説明する。
- MBTIの名称、4文字コード、既存タイプ名は使用しない。
- 人を優劣や相性の良し悪しで評価しない。
- 結果の根拠となる回答を表示できる、説明可能な採点にする。
- 心理検査ではなく、会話のきっかけを作るエンターテインメントとして扱う。

## 2. 4つの性格軸

| 軸         | マイナス側               | プラス側               | 測る内容                       | 同点決定質問 |
| ---------- | ------------------------ | ---------------------- | ------------------------------ | ------------ |
| つながり方 | 自分のペースを大切にする | 一緒に共有したい       | 人との距離感、連絡、回復方法   | Q16          |
| 進め方     | 流れに合わせたい         | 計画して安心したい     | 予定、段取り、生活の整え方     | Q21          |
| 決め方     | 理由と納得を重視する     | 気持ちと共感を重視する | 判断、相談、意見の違いへの対応 | Q14          |
| 求めるもの | 安心と継続を重視する     | 変化と経験を重視する   | 休日、お金、成長、新しい体験   | Q24          |

両極はどちらも肯定的な特徴として扱う。「内向的」「無計画」「感情的」など、片方を否定的に見せる名称は使用しない。

## 3. 採点方式

各質問は1つの主軸だけを測る。4選択肢には次のいずれかを明示的に設定する。

- `-2`: マイナス側へ強く寄る
- `-1`: マイナス側へ少し寄る
- `+1`: プラス側へ少し寄る
- `+2`: プラス側へ強く寄る

各軸は6問で構成し、理論上の得点範囲は`-12〜+12`とする。画面表示用の位置は次式で`-100〜+100`へ正規化する。

```text
position = round(rawScore / 12 * 100)
```

- `rawScore < 0`: マイナス側
- `rawScore > 0`: プラス側
- `rawScore = 0`: その軸の同点決定質問で選んだ側
- `abs(rawScore) <= 2`: 結果画面では「バランス型」と併記

配列順による同点優先は使用しない。

## 6. 結果表示

無料結果で最低限表示するもの:

1. 2人それぞれの関係スタイル名
2. タグライン
3. 4軸上の位置
4. 各軸の短い傾向名
5. 結果につながった代表回答
6. 2人で最も近い軸と、違いが出た軸
7. 従来の価値観の近さと相互理解度

既存の「カフェ・旅人・森・灯台・焚き火・図書館・海・庭園」は判定名ではなく、関係スタイルを表現する画像モチーフとして使用する。

## 7. 互換性と保存データ

新規セッションには必ず次を保存する。

```json
{
  "scoringVersion": "v2"
}
```

参加者データには回答完了時に次を保存する。

```json
{
  "scoringVersion": "v2",
  "styleKey": "shared-flexible-feeling-stable",
  "worldKey": "cafe",
  "axisScores": {
    "connection": 4,
    "structure": -2,
    "decision": 8,
    "novelty": -5
  }
}
```

- `scoringVersion`がない既存セッションは`v1`として扱う。
- `v1`には旧質問文・旧選択肢・旧世界観判定を使用する。
- ローカル保存された旧回答を`v2`質問へ再利用しない。
- 新旧とも回答数24、予想回答数8を維持する。

## 8. 完了条件

- 全24問が4軸のいずれか1つに割り当てられている。
- 各軸が6問で構成される。
- 全選択肢に`-2/-1/+1/+2`のいずれかが明示される。
- 16通りの符号組み合わせすべてに一意の関係スタイルが存在する。
- 同点時に配列順で結果が決まらない。

- 旧セッションが旧質問と旧判定で表示できる。
- 結果画面に4軸、関係スタイル、代表回答が表示される。
- スマートフォン幅で横スクロールや文字切れがない。
- lint、TypeScript、production build、判定検証スクリプトが成功する。
